# 操作界面与命令合同

产品首先提供 CLI，随后提供运维网页。两者调用同一应用层，显示同一真实状态。命令名称和 HTTP 路径在实现时确定；本文件中的操作名是语义名称，不是已可执行的命令。

## 操作合同

| 操作 | 输入 | 输出与副作用 |
|---|---|---|
| config validate/show/diff | profile、候选配置 | 结构/引用错误、脱敏有效值、版本差异；只读 |
| source inspect/preview | 来源与窗口 | 覆盖范围、可用性、预计处理量；标明是否访问网络，不推进游标 |
| run generate | 管线、日期/游标、隔离输出位置 | 草稿、覆盖说明、阶段结果；不发业务消息、不消费反馈 |
| run start/resume/cancel | 管线、范围、命令幂等键 | task/run ID；开始、恢复或取消未完成部分 |
| run list/show | 时间、来源、状态、分页 | 阶段、失败、产物、预算和投递关联 |
| delivery inspect/reconcile | 投递 ID、核验证据 | 实际目标/部件/回执；核验留下操作者和原因 |
| delivery retry | 明确可重试的未发部件 | 复用原计划，不能重复 confirmed 部分 |
| delivery resend/correct | 来源或投递、明确目标、原因 | 新计划/修订，保留已发送历史与重复风险说明 |
| feedback inspect/apply | 事件范围、规则修订 | inbox、候选规则及采用回执；预览不消费 |
| knowledge build/query/release/rollback | 索引范围、候选代际、评测与发布决定 | 产物、来源、查询开关与代际；各操作副作用独立 |
| schedule list/plan/apply/pause | 计划与版本 | 预览差异、冲突、下次触发、应用回执 |
| data export/import/repair/cleanup | 目录、清单、范围、预览/应用 | 校验、差异、隔离项和恢复结果 |
| diagnostics/health | 范围与只读模式 | 组件可用性、覆盖、写入者、版本与最近错误 |

所有写命令接受幂等键；相同键和相同内容返回同一结果，相同键不同内容报冲突。异步任务返回 ID，不占用网页请求一直等待整份日报。批量操作先显示条数、来源与目标；请求取消返回“已接受取消”，随后展示实际停在哪个阶段。

CLI 同时支持人类可读与机器可读结果。退出码描述命令执行结果，JSON 中保留业务状态、失败部件和部分结果；不能把进程退出 0 等同所有消息已送达。帮助包含副作用和示例，示例由实现的合同测试校验。

## 网页的信息结构

| 页面 | 必须回答的问题 | 主要动作 |
|---|---|---|
| 概览 | 今天哪些来源未覆盖、哪些投递待确认、系统是否积压？ | 跳到来源/运行/待确认；无需大屏装饰指标 |
| 来源与订阅 | 读哪些范围、投到哪里、上次完整采集是什么时候？ | 预览、启停、配置变更；名字和稳定身份同时可见 |
| 运行详情 | 输入覆盖、生成、发送、降级分别发生了什么？ | 查产物、恢复、取消；展示版本与每阶段耗时 |
| 投递与复核 | 哪些部件确认、过滤、失败或不确定？ | 查来源和目标，核验、重试、明确补发 |
| 内容与搜索 | 从哪里来、何时发生、为什么召回、是否仍可访问？ | 原文、多个来源、归档和内容版本；反馈意图 |
| 成长与反馈 | 队列、配额、原话、卡片选择和 rubric 如何变化？ | 看切片、预览周报、采用反馈修订 |
| 调度与配置 | 什么时间、在哪个执行者上生效，变更会影响什么？ | 预览、版本差异、应用、暂停 |
| 诊断与数据 | 各组件版本、备份、同步/索引新鲜度是否正常？ | 脱敏导出、预览清理、恢复演练报告 |

最小网页可以先实现概览、运行详情和投递复核的只读视图。交互写入上线后再完成其他页面；核心投递不得依赖网页可用。

## 交互状态

每页具有加载、无数据、筛选后为空、部分不可用、失败、过期数据和无权限状态。过期数据保留最后更新时间与手动刷新，不把旧成功涂成当前健康。错误信息给具体可操作原因，详细技术堆栈收进诊断区。

表格分页、按稳定字段排序、保留筛选条件；长正文按需加载。窄屏能阅读主要状态和执行恢复任务，键盘可操作，焦点与表单错误可见；不能仅靠颜色区分 confirmed 与 ambiguous。后台刷新不能重置用户正在审阅的条目或表单。

重试按钮只对允许重试的部件可用。补发展示目标、源成员、已确认部件和可能重复的范围，提交后显示命令 ID。清理、切换写入者和改路由等高影响操作有一次针对具体影响的确认；无需对普通查看重复弹窗。

## 后端与网页的安全边界

网页默认绑定回环地址；需要局域网或远程使用时启用明确的身份认证与 TLS/可信隧道配置。反向代理认证可以满足个人部署，不强制建设多租户账户系统。写操作验证服务端权限、请求来源和幂等键；cookie 会话需 CSRF 防护。

对聊天内容、Markdown、URL 和模型输出进行转义/净化。禁止把归档路径直接作为任意文件读取入口；下载受内容 ID 和权限约束。所有写操作产生 actor、reason、配置版本、命令与结果审计。密钥只显示“已配置/未配置”或安全指纹，前端不获取可用秘密。

## API 的最小一致性要求

查询支持分页和范围过滤；写命令使用版本前置条件，过期配置编辑报冲突。响应至少能表达 `command_id/run_id`、业务状态、结构化错误、可重试性和关联产物。任务状态与提交后的结果可再次获取。实现可以选 REST、RPC 或其他方式；HTTP 路径和字段 schema 在选型后生成，并与 CLI 测试共用 fixture。
