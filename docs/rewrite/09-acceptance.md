# 验收用例

本文件定义新实现应通过的观察结果，**当前所有 AT 用例均为待实现、待执行**。文档校验通过只表示规格结构与引用有效。

每个用例保存输入/配置版本、执行命令、环境、状态前后差异和产物 hash；真实投递另附目标与 message IDs，公开报告脱敏。合成样例从 [examples.json](contracts/examples.json) 开始扩展；性能负载见 [质量文档](07-quality.md)。

自动化分为纯合同测试、使用实际存储的组件故障测试、CLI到模拟HTTP的隔离集成、真实测试目标四层。前两层先覆盖状态边界，真实测试需接入阶段单独配置。
## 输入与日报

<a id="at01"></a>
### AT01 空配置与按能力依赖

适用：[F01](02-capabilities.md#f01)。

条件：只启用频道原文；无摘要密钥。

通过结果：配置校验通过；实际所需来源/目标缺失时给字段级错误；不初始化摘要模型。

<a id="at02"></a>
### AT02 路由变更与 fallback

适用：[F01](02-capabilities.md#f01)、[F07](02-capabilities.md#f07)。

条件：任务冻结目标后修改路由；另造缺失路由。

通过结果：普通改版在途使用原快照；新任务用新版本；安全/隐私授权撤销后未发部件暂停且不自动转投；无安全 fallback 留待处理，告警不泄密。

<a id="at03"></a>
### AT03 微信冷启动与坏导出

适用：[F02](02-capabilities.md#f02)。

条件：已有完整归档，新导出为空/截断/超时。

通过结果：原档不被覆写；显示不完整与重试预算；其他来源继续。

<a id="at04"></a>
### AT04 日期边界与大窗口

适用：[F03](02-capabilities.md#f03)。

条件：窗口起点、终点、同一时间多条及超过分页大小的消息。

通过结果：半开区间准确；分页覆盖所有或给明确缺口；不是只返回最新一页。

<a id="at05"></a>
### AT05 附件缓存与媒体失败

适用：[F02](02-capabilities.md#f02)、[F03](02-capabilities.md#f03)、[F05](02-capabilities.md#f05)。

条件：一条正文有缓存图，一条图下载失败。

通过结果：身份正确的缓存被复用；失败不丢正文；来源与媒体缺口可查。

<a id="at06"></a>
### AT06 摘要核验与坏结构

适用：[F04](02-capabilities.md#f04)。

条件：初稿有效，核验失败；再造所有输出都无正文。

通过结果：前者保留初稿与未完成核验状态；后者失败并保留材料，不写完成。

<a id="at07"></a>
### AT07 引用与富消息回落

适用：[F04](02-capabilities.md#f04)、[F05](02-capabilities.md#f05)。

条件：重复/不存在的图标记；富消息明确格式错误。

通过结果：引用仅保留有效项；回落文本，所有来源仍在；无重复正文。

<a id="at08"></a>
### AT08 日期重跑与更正

适用：[F04](02-capabilities.md#f04)、[F18](02-capabilities.md#f18)。

条件：同一日报已确认；重跑、只生成新稿、显式更正。

通过结果：普通重跑不发；完整覆盖无内容不重复消耗模型；迟到材料补档不自动重发；无外部尝试的计划可原子换版，首段已发后编辑不得拼入新尾段；仅更正命令产生新计划并关联旧版。

## 频道、投递与去重

<a id="at09"></a>
### AT09 行过滤与整帖过滤

适用：[F06](02-capabilities.md#f06)。

条件：同一条包含广告行和有效正文；另一条命中整帖排除。

通过结果：前者只删命中行；后者保存规则审计；误配可定位并恢复。

<a id="at10"></a>
### AT10 相册与长 caption

适用：[F06](02-capabilities.md#f06)、[F07](02-capabilities.md#f07)。

条件：可靠分组相册、无分组连续空文、两条相邻有正文帖。

通过结果：完整保留成员；不合并两条独立正文；长 caption 的部件关系可恢复；私有纯媒体无法取得且无有效来源定位时留待恢复，不发空卡。

<a id="at11"></a>
### AT11 部分媒体/正文发送

适用：[F06](02-capabilities.md#f06)、[F07](02-capabilities.md#f07)。

条件：媒体确认后正文明确失败，或混合相册只成功部分。

通过结果：只补未确认部件；既有目标 IDs 保留；必需媒体明确失败后允许的文字替代可满足同一义务，重启不重发正文；degraded 不伪装整组完整。

<a id="at12"></a>
### AT12 服务端接收但响应丢失

适用：[F07](02-capabilities.md#f07)。

条件：分别模拟文本、富消息、封面和相册请求已接收后超时，再重启执行者。

通过结果：记录 ambiguous；不自动再次 POST，也不改用纯文或重发整组；相册不确定部件暂停依赖后续；可绑定人工/读回证据恢复。

<a id="at13"></a>
### AT13 分块断点与 payload 修订

适用：[F07](02-capabilities.md#f07)。

条件：三块第1成功第2失败；恢复前生成不同正文。

通过结果：原计划只恢复未确认块；新正文另建 revision，不拿旧计数跳过新文。

<a id="at14"></a>
### AT14 核心记录与派生记录故障

适用：[F07](02-capabilities.md#f07)、[F19](02-capabilities.md#f19)。

条件：分别断主库、断紧急日志、断索引/ledger。

通过结果：行为匹配 D01 所选策略；主文已发不因派生失败重发；修复积压可见。

<a id="at15"></a>
### AT15 空洞与积压

适用：[F06](02-capabilities.md#f06)、[F18](02-capabilities.md#f18)。

条件：低 ID 失败、高 ID 成功；停机跨日后恢复。

通过结果：低 ID 仍在恢复范围；默认可越过失败空洞继续并注明补发原时间；严格顺序 profile 等待同源，其他源继续；抓取游标不伪装送达；积压不因日期窗消失。

<a id="at16"></a>
### AT16 同链接新增事实

适用：[F08](02-capabilities.md#f08)。

条件：裸链接重复、同链接新评论、不同身份参数。

通过结果：按明确规则处理；不把所有同链接内容抑制；身份参数保留；启用 first-arrival 时改变 worker 完成顺序不改变同批决定，稳定排序/胜出依据可查。

<a id="at17"></a>
### AT17 去重关闭与审计失败

适用：[F08](02-capabilities.md#f08)、[F09](02-capabilities.md#f09)。

条件：关闭频道去重；另让终态决定持久化失败。

通过结果：关闭后相似内容仍可投递但同一投递不重发；无法审计不执行规则终态。

<a id="at18"></a>
### AT18 report 与模式降级

适用：[F09](02-capabilities.md#f09)。

条件：配置请求 enforce，但人工批准/覆盖/代际不足。

通过结果：有效模式降级可见；实际仍投递；假设 skip 不进入已抑制计数。

<a id="at19"></a>
### AT19 同事件新增与独特媒体

适用：[F09](02-capabilities.md#f09)。

条件：none/minor/substantial、不同图同 caption、不确定判定。

通过结果：动作符合 F09；独特媒体不被 caption-only 判断吞掉。

<a id="at20"></a>
### AT20 模型预算与代际隔离

适用：[F09](02-capabilities.md#f09)、[F16](02-capabilities.md#f16)。

条件：主判定超时、fallback 坏结构、预算耗尽、换维度。

通过结果：有界退出增强；无混合代际；不能自动打开 enforce 或发布查询。

## 订阅、成长与健康

<a id="at21"></a>
### AT21 B站 UID 与专栏订阅

适用：[F10](02-capabilities.md#f10)。

条件：作者改名、黑名单、视频订阅但未开文章。

通过结果：稳定 ID 匹配；黑名单排除；未开启专栏不抓作已订阅内容；缺专栏全文仍可交付元数据卡；直链/播放器入口保留规范 URL。

<a id="at22"></a>
### AT22 B站限流与积压公平

适用：[F10](02-capabilities.md#f10)、[F18](02-capabilities.md#f18)。

条件：一源 -352；高产与低产源同时积压。

通过结果：有界暂停/退避，无请求风暴；已保存低产待发项不长期饥饿。

<a id="at23"></a>
### AT23 订阅卡片降级与账本

适用：[F10](02-capabilities.md#f10)、[F11](02-capabilities.md#f11)。

条件：摘要/封面失败；发送确认、明确失败、不确定各一条。

通过结果：文字可交付；仅确认进入确认账本；其他按 F07 保持对应状态。

<a id="at24"></a>
### AT24 YouTube 时长与源级路由

适用：[F11](02-capabilities.md#f11)。

条件：已知短/长、未知时长、#shorts；频道覆盖目标。

通过结果：按 profile 筛选；未知不伪造时长；正确目标；RSS故障覆盖可查询。

<a id="at25"></a>
### AT25 机会合并与批次重放

适用：[F12](02-capabilities.md#f12)。

条件：相同机会分享 URL、同批两次导入、中途失败恢复。

通过结果：稳定合并；mention_count 不重复增加；死亡信号和旧状态可追溯。

<a id="at26"></a>
### AT26 派生视图故障

适用：[F12](02-capabilities.md#f12)、[F04](02-capabilities.md#f04)。

条件：机会库成功但 Markdown 生成失败。

通过结果：日报继续；事实库可读；重建视图不再次计入业务事件。

<a id="at27"></a>
### AT27 成长引用真实性

适用：[F13](02-capabilities.md#f13)。

条件：模型给虚构 ID、改写金句、跨界片段及有效片段。

通过结果：无效项拒绝或复核；有效引用逐字来自归档；部分失败不标整日完成。

<a id="at28"></a>
### AT28 领取、崩溃与配额

适用：[F13](02-capabilities.md#f13)、[F18](02-capabilities.md#f18)。

条件：两个 worker 同取卡且争最后一个额度；多段卡；发送中租约过期；跨业务日。

通过结果：仅一个可发送并原子占用额度；多段只计一张；旧 owner 被隔离；sending 先核验；明确未发释放、歧义保留；重启和跨日配额连续。

<a id="at29"></a>
### AT29 A/B 退路

适用：[F13](02-capabilities.md#f13)。

条件：B卡失败或 judge 不可用。

通过结果：可用 A 卡继续；保存选择与失败；确认/歧义分别消耗或预留配额。

<a id="at30"></a>
### AT30 入站反馈幂等与所有权

适用：[F14](02-capabilities.md#f14)。

条件：同批重到、payload 冲突、另一 consumer 已持有 Bot。

通过结果：先存再确认；重复不重消费；冲突显式失败；不抢 offset。

<a id="at31"></a>
### AT31 周报预览和失败恢复

适用：[F14](02-capabilities.md#f14)。

条件：预览周报、规则合并失败、发送失败、同周重跑。

通过结果：预览不消费或改规则；反馈可恢复；确认后不重发；歧义单独待核验。

<a id="at32"></a>
### AT32 健康缺失与睡眠探测

适用：[F15](02-capabilities.md#f15)。

条件：睡眠未同步、部分测量缺失、历史基线不足。

通过结果：立即继续日报；缺口与样本数明确；不以零填缺失或编造趋势。

## 知识、调度与界面

<a id="at33"></a>
### AT33 知识来源冲突与 Podcast

适用：[F16](02-capabilities.md#f16)、[F20](02-capabilities.md#f20)。

条件：多目标同内容、错配 URL/producer/ID、损坏 SRT、metadata-only/source-only 和机会库新接入。

通过结果：保留多个真实链接；冲突隔离；同条 txt 可降级；metadata/source_only 不冒充原文或已送达；机会库新适配单独对账；不按标题猜配。

<a id="at34"></a>
### AT34 索引发布与回滚

适用：[F16](02-capabilities.md#f16)。

条件：构建成功但未批准、canary失败、kill switch、代际回滚。

通过结果：普通查询维持门控；候选不自动开放；可回到已验证代际。

<a id="at35"></a>
### AT35 检索权限与内容注入

适用：[F16](02-capabilities.md#f16)、[F21](02-capabilities.md#f21)。

条件：两个权限范围的近似正文；恶意 Markdown/来源指令。

通过结果：权限过滤后检索/展示；旧数据缺权限元信息时仅导入操作者可见；不执行来源指令；HTML/URL 安全处理。

<a id="at36"></a>
### AT36 意图事件与投影

适用：[F17](02-capabilities.md#f17)。

条件：四类事件、幂等冲突、无文档关联、重新分类。

通过结果：原始事件保留；同键冲突拒绝；pending 保留；投影可重建。

<a id="at37"></a>
### AT37 错过触发与在途改计划

适用：[F18](02-capabilities.md#f18)。

条件：睡眠/重启漏日任务；长任务中调整计划。

通过结果：按声明补跑且不双跑；计划预览与生效版本可查；不误停在途。

<a id="at38"></a>
### AT38 跨机单写者与旧 owner 恢复

适用：[F18](02-capabilities.md#f18)、[F20](02-capabilities.md#f20)。

条件：两个主机争用同范围；旧进程在检查 owner 后暂停，切主后恢复并试图 POST。

通过结果：发送出口或旧执行环境阻断旧 POST；不能只测数据库拒绝旧提交；只有有效 owner 可发；分区状态明确。

<a id="at39"></a>
### AT39 状态解释与告警闭环

适用：[F19](02-capabilities.md#f19)。

条件：无内容/采集失败/过滤/待发/歧义/恢复各一条。

通过结果：诊断区分原因；重复故障合并；告警失败不递归；输出脱敏。

<a id="at40"></a>
### AT40 快照篡改、缩水与时效

适用：[F20](02-capabilities.md#f20)。

条件：坏 hash、删旧行、改旧 caption、过期/未来时间。

通过结果：保留旧有效快照；停止依赖它的抑制；主文继续；失败原因可查。

<a id="at41"></a>
### AT41 CLI/Web 命令一致性

适用：[F21](02-capabilities.md#f21)。

条件：重复提交同键、同键异文、过期配置编辑。

通过结果：相同命令只执行一次；异文冲突；版本冲突；两界面显示同一结果。

<a id="at42"></a>
### AT42 页面状态与窄屏

适用：[F21](02-capabilities.md#f21)。

条件：加载/空/错/过期/无权限/部分失败；键盘与窄屏操作。

通过结果：状态不混淆；焦点清楚；长列表分页；刷新不破坏待审阅操作。

<a id="at43"></a>

### AT51 安装、升级与回滚包

适用：[F01](02-capabilities.md#f01)、[F18](02-capabilities.md#f18)、[F22](02-capabilities.md#f22)。

条件：空环境安装，schema升级中断，配置回退。

通过结果：可从文档操作；中断可恢复；不覆盖旧业务事实；帮助示例通过合同测试。

<a id="at52"></a>
### AT52 停用、删除与保留清理

适用：[F04](02-capabilities.md#f04)、[F06](02-capabilities.md#f06)、[F22](02-capabilities.md#f22)。

条件：有未完成投递的源停用，过期缓存和被引用原档同在。

通过结果：停止未来采集；历史和在途按明确政策；清理预览不删在途证据。

<a id="release-gates"></a>
## 生产接管门

每个接管 profile 都需要：

1. 启用的 F 编号全部映射到可运行实现，关联 AT 有实际结果；未启用功能有保留决定。
2. D01、D02、D04、D07 形成对应 profile 决定，模型/去重发布仍满足独立批准门。
3. 空环境安装、离线恢复、幂等导入、单写者切换、切换后回滚通过。
4. 测试目标验证文本、长文、媒体/相册及实际降级路径；目标 IDs 能与源成员和计划对上。
5. 影子差异已解释；性能、预算、完整性和内容质量达到事先固定的门槛。
6. 真实定时运行观察包含启用的调度周期、失败与恢复；本地通过、测试环境通过和生产通过分别报告。
7. 配置/命令文档从当前定义生成，模板和分发包校验和一致；许可证与原始证据保留。

使用 [发布报告模板](templates/release-report.md) 给出每一项的结果、未通过项和接管范围。M4 的局部接管不表示 F21 完整网页或整个重写已完成。
