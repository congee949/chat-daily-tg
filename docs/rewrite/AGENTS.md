# 新实现工作约定

本目录的入口是 [README.md](README.md)。把本目录带入新仓库后，按这里的功能合同独立设计和实现。业务要求、外部兼容格式与验收结果需要保持，旧类名、函数、目录、脚本、表结构与进程布局不需要复刻。

先交付一条可运行的端到端路径，再逐项完成 [功能覆盖表](contracts/coverage.json)。每个已实现功能必须有对应验收证据；实验、测试环境和生产结果分别记录。

状态迁移和失败恢复以 [领域与投递状态](03-domain-and-delivery.md) 为准。禁止把抓取完成、已过滤、发送不确定或模型推断当作确认送达。可选增强失败必须有正文退路。

技术选择写入 [决策登记](10-decisions.md)；每次只为当前规模引入需要维护的组件。并行实现前划定文件和合同所有权，不相互覆盖改动。

默认运行合成数据和隔离模式。真实接入使用单独的数据目录与测试目标。提交、推送、切换生产写入者、停用原任务及删除数据均由对应的明确操作指令驱动。

文档使用项目作者口吻。功能描述进入功能合同，架构决定进入 ADR，测量进入带版本的报告，试验记录进入独立过程目录。生成器和模板必须与对外文档同步更新。
